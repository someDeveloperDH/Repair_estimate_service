# data1 — 신발 종류 데이터 정보

작성일: 2026-10-14. 실제 원본 라벨과 생성된 학습 데이터 기준입니다.

## 1. 총 몇 장인가?

| 구분 | 이미지 수 |
|---|---:|
| 원본 라벨 JSON에 등록된 전체 이미지 | 8,754장 |
| `pic.zip`과 파일명으로 매칭된 이미지 | 8,754장 |
| 라벨이 있는 이미지 → 최종 학습 데이터 | **5,746장** |
| 라벨이 없어 제외한 이미지 | 3,008장 |
| 사진 누락으로 제외한 이미지 | 0장 |

최종 데이터에는 **10,912개 바운딩 박스**가 있습니다. 한 이미지에 여러 신발이 있으면 박스도 여러 개이므로 이미지 수와 라벨 수가 다릅니다.

## 2. Task 및 원본 위치

- 목적: 사진 안의 신발 위치를 찾고 신발 종류를 구분합니다.
- 원본 사진: `raw/pic.zip`
- 원본 라벨: `raw/data1/shoe_20260924_1030.zip` 안의 `annotations/instances_default.json`
- 원본 형식: COCO 객체 탐지 라벨. 박스는 `[x, y, width, height]`입니다.
- 변환 결과: `datasets/data1/`의 YOLO 객체 탐지 데이터입니다. 이미지 전체에 단일 종류를 부여하는 분류 형식은 아닙니다.

## 4. 학습·검증·테스트 구성

| 구분 | 이미지 수 | 박스 수 |
|---|---:|---:|
| train | 4,368 | 8,382 |
| val | 557 | 976 |
| test | 821 | 1,554 |
| **합계** | **5,746** | **10,912** |

클래스별 **박스 수**는 다음과 같습니다.

| 클래스 | train | val | test | 합계 |
|---|---:|---:|---:|---:|
| sneakers | 6,492 | 764 | 1,223 | 8,479 |
| formal | 453 | 50 | 75 | 578 |
| boots | 986 | 78 | 112 | 1,176 |
| sandals | 203 | 16 | 14 | 233 |
| slippers | 66 | 0 | 1 | 67 |
| heels | 93 | 20 | 1 | 114 |
| others | 89 | 48 | 128 | 265 |

파일명 앞 8자리의 촬영 날짜를 기준으로 묶고, 날짜 해시로 약 80/10/10 비율을 배정했습니다. 날짜별 사진 수가 달라 실제 이미지 비율은 다릅니다. 같은 날짜는 두 task 모두 같은 split에 들어갑니다. 다른 날짜에 동일 신발이 있는지는 개체 ID가 없어 확인하지 못했습니다.

## 5. 해상도와 전처리

| 최종 사진 해상도 | 이미지 수 |
|---|---:|
| 512 × 512 | 5,741 |
| 512 × 683 | 5 |

- 사진 자체는 ZIP에서 추출했으며 변환 과정에서 재인코딩하지 않았습니다.
- YOLO 라벨: `class_id center_x center_y width height`, 좌표 범위는 0~1입니다.
- 원본 이미지 너비·높이로 박스를 정규화했습니다.
- 이미지 경계를 벗어난 박스 4개는 경계 안으로 잘랐습니다.
- 종횡비 불일치 이미지 및 유효하지 않은 박스는 0개입니다.
- 라벨 없는 사진은 정상/미작업 여부가 불명확하여 학습에 포함하지 않았습니다.
