# data2 — 운동화 손상 부위 데이터 정보

작성일: 2026-10-14. 실제 원본 라벨과 생성된 학습 데이터 기준입니다.

## 1. 총 몇 장인가?

| 구분 | 이미지 수 |
|---|---:|
| 원본 라벨 JSON에 등록된 전체 이미지 | 12,599장 |
| 원본에서 라벨이 있는 이미지 | 2,786장 |
| `pic.zip`과 파일명으로 매칭된 전체 이미지 | 6,401장 |
| 매칭되고 라벨이 있는 이미지 → 최종 학습 데이터 | **1,465장** |
| 매칭되지만 라벨이 없어 제외한 이미지 | 4,936장 |
| 사진이 없는 전체 이미지 | 6,198장 |
| 위 사진 누락 중 라벨이 있는 이미지 | 1,321장 |

최종 데이터에는 **2,465개 바운딩 박스**가 있습니다. 원본의 4,549개 박스 중 사진이 매칭되지 않는 이미지의 2,084개 박스는 포함되지 않았습니다.

전체 등록 이미지의 구성은 `1,465장(사용) + 4,936장(라벨 없음) + 6,198장(사진 없음) = 12,599장`입니다. 사진 누락 중 라벨이 있는 1,321장은 6,198장의 일부이므로 별도로 더하지 않습니다.

## 2. Task 및 원본 위치

- 목적: 운동화 손상 부위의 위치와 부위 종류를 탐지합니다.
- 원본 사진: `raw/pic.zip`
- 원본 라벨: `raw/data2/label2.zip` 안의 `annotations/instances_default.json`
- 원본 형식: COCO 객체 탐지 라벨. 박스는 `[x, y, width, height]`입니다.
- 변환 결과: `datasets/data2/`의 YOLO 객체 탐지 데이터입니다.
- 손상 부위는 `outsole`, `heel lining` 2종이며 예외 클래스 `not_sneakers`를 포함합니다. 손상 종류·심각도·정상 여부에 대한 별도 클래스는 없습니다.

## 3. 클래스 목록 및 개수

| COCO ID | YOLO ID | 라벨명 | 의미 | 원본 박스 수 | 최종 박스 수 | 최종 클래스 포함 이미지 |
|---:|---:|---|---|---:|---:|---:|
| 1 | 0 | outsole | 밑창·아웃솔 | 726 | 358 | 280 |
| 2 | 1 | heel lining | 뒤꿈치 안쪽 안감 | 3,808 | 2,101 | 1,194 |
| 3 | 2 | not_sneakers | 운동화가 아닌 신발 | 15 | 6 | 6 |
| | | **합계** | | **4,549** | **2,465** | |

한 사진에 여러 박스나 클래스가 있을 수 있으므로 클래스 포함 이미지 수를 합하면 전체 이미지 수와 다를 수 있습니다. 뒤꿈치 안감에 라벨이 집중되어 있고 `not_sneakers`는 매우 적습니다.

## 4. 학습·검증·테스트 구성

| 구분 | 이미지 수 | 박스 수 |
|---|---:|---:|
| train | 1,222 | 2,057 |
| val | 131 | 207 |
| test | 112 | 201 |
| **합계** | **1,465** | **2,465** |

클래스별 **박스 수**는 다음과 같습니다.

| 클래스 | train | val | test | 합계 |
|---|---:|---:|---:|---:|
| outsole | 320 | 21 | 17 | 358 |
| heel lining | 1,731 | 186 | 184 | 2,101 |
| not_sneakers | 6 | 0 | 0 | 6 |

파일명 앞 8자리의 촬영 날짜를 기준으로 묶고, 날짜 해시로 약 80/10/10 비율을 배정했습니다. 날짜별 사진 수가 달라 실제 이미지 비율은 다릅니다. 같은 날짜는 두 task 모두 같은 split에 들어갑니다. 다른 날짜에 동일 신발이 있는지는 개체 ID가 없어 확인하지 못했습니다.

## 5. 해상도와 좌표 변환

- 최종 사용 사진은 **1,465장 모두 512 × 512**입니다.
- 원본 라벨 JSON은 고해상도 사진 기준 좌표를 사용합니다. 예를 들어 같은 파일명의 라벨은 3456 × 3456 기준이고 실제 제공 사진은 512 × 512입니다.
- 원본 라벨에 기록된 너비·높이로 박스를 0~1로 정규화하여 축소 사진에 대응했습니다. 원본 픽셀 좌표를 512 크기에 그대로 적용하지 않았습니다.
- 사용 사진 전체의 종횡비를 검사했으며 불일치 0장입니다. 동일 파일명의 축소본이라는 전제이며, 사진의 크롭 여부를 개별 수동 검토한 것은 아닙니다.
- 사진은 재인코딩 없이 추출했습니다. 경계를 잘라야 하는 박스 및 유효하지 않은 박스는 0개입니다.
- YOLO 라벨 한 줄: `class_id center_x center_y width height`.

## 6. 제외 데이터 및 평가 한계

- 사진이 없는 이미지의 목록과 라벨 존재 여부는 `missing_images.csv`에 기록되어 있습니다. 원본 사진을 추가하면 변환 코드로 다시 생성할 수 있습니다.
- 라벨 없는 사진은 정상 사진인지 미작업 사진인지 확인되지 않아 제외했습니다. 빈 라벨을 정상 데이터로 간주하지 않았습니다.
- 따라서 정상 운동화에서 오탐이 얼마나 발생하는지 평가하려면 확인된 정상 이미지가 추가로 필요합니다.
- `not_sneakers`는 train에만 6개 있고 val/test에는 없어, 현재 분할로 이 클래스의 일반화 성능은 평가할 수 없습니다.
- 손상 심각도나 손상 유무의 이진 분류 데이터로 바로 해석할 수 없습니다.
