# 모델별 전체 사진 재평가와 이미지·자연어 보고서

## 실행 범위

저장된 4개 최적 체크포인트를 다시 로딩하고, 기존 예측 파일을 재사용하지 않고 사진에서 처음부터 추론합니다.

| 모델 실험 | 저장 epoch | 입력 방식 |
|---|---:|---|
| data1_long30 | 24 | 신발 종류, 전체 프레임 |
| data2_long30 | 25 | 손상, 전체 프레임 |
| data2_tiles30 | 3 | 손상, 전체 프레임+타일 4개 |
| data2_tiles_balanced30 | 5 | 손상, 전체 프레임+타일 4개 |

밑창·안감 점수를 함께 검사하며 모든 표시 후보를 별도로 설명합니다. 표시 임계값은 0.25로 고정하고, 같은 클래스의 양의 면적 교집합을 일대일 매칭해 평가합니다. 비교용 IoU≥0.5 및 표준 COCO AP도 저장합니다. 이 실행에서 모델·임계값을 결과에 맞춰 조정하지 않습니다.

## 사진 수

- val: 신발 종류 557장, 손상 131장. 같은 파일명을 제외하면 601장. 모델 적용은 557+131×3=950건.
- test: 신발 종류 821장, 손상 112장. 같은 파일명을 제외하면 841장. 모델 적용은 821+112×3=1,157건.

2026-10-16 준비 시점에 데이터 폴더에서 센 값입니다. 같은 파일명의 두 task 사진은 각기 다른 정답을 사용해 각각 평가합니다. 입력 분할은 사용자 확인 후 선택합니다. test를 선택하면 탐색적 설명·오류 분석까지 열어보는 평가이며, 이후 같은 test에 맞춰 모델을 개선한 뒤 독립 시험이라고 주장할 수 없습니다.

## 산출물

새 출력 폴더의 index.html에서 모델별 사진을 누르면 각 사진 보고서를 볼 수 있습니다.

```text
<새 출력 폴더>/
  frozen_config.json       # 시작 전 고정 설정·체크포인트 해시
  status.json              # 완료 수·실패·실행 중 예상 잔여 시간
  index.html               # 전체 사진 보고서 목록
  comparison.csv           # 모델·클래스별 평가 지표
  <모델>/
    metrics.json
    records.json / records.jsonl
    image_summary.jsonl
    standard_coco/
    images/<사진명>/
      original.jpg
      predictions.png      # P 번호와 모델 클래스·점수
      ground_truth.png     # G 번호와 등록 정답, 초록색
      overlay.png          # 실선 예측·점선 정답
      comparison.jpg       # 예측 / 정답 / 겹침 3열
      report.md / report.html
      trace.json
```

각 검출의 설명은 출처 뷰·실제 query 슬롯·디코더 단계별 점수·정답 매칭·5개 영역 흐림 비교에 근거합니다. 고정 query와 같은 위치의 대체 후보를 함께 추적해 슬롯 교체를 잘못된 원인 설명으로 쓰지 않습니다. 원인 가설과 관측 결과를 구분합니다. 별도 언어모델이나 외부 업로드는 사용하지 않습니다.

이번 배치에는 앞서 시연한 5개 영역 흐림 비교를 포함합니다. 사진마다 64개 패치를 순회하는 추가 격자 민감도 지도는 포함하지 않습니다. 여러 검출이 있는 사진도 입력 뷰별 순방향 계산을 공유하고, 반복되는 대조 실험은 재사용합니다.

## 명령

```powershell
.venv/Scripts/python.exe -u -m pipeline.batch_review `
  --split val `
  --output artifacts/batch_review_<실행시각>
```

test를 선택한 경우 --split test를 명시합니다. --limit은 사전 점검용이며 전체 실행에서는 기본값 0을 유지합니다. --models를 지정하지 않으면 4개 모두 실행합니다. 기존 출력 폴더를 덮어쓰지 않습니다.

## 사전 확인

전체 테스트 38개 통과. 각 모델에서 기존 val 사진 1장씩 총 4건을 실제 새로 추론해 이미지·자연어·원시 근거·평가 저장을 확인했습니다. 모델 로딩을 제외한 해당 사전 점검의 건별 처리 시간은 약 0.20~0.95초였습니다. 사진별 검출 수에 따라 시간이 늘어나므로 전체 예상은 val 10~20분, test 15~25분으로 안내합니다. 전체 실행은 대상 분할 선택 후 시작합니다.
