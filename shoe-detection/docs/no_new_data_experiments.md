# 추가 데이터 없이 개선하는 실험 계획

작성일: 2026-10-16 (한국 시간)

## 현재 상태

기준 실행: `artifacts/local_gpu_20261015_213427`.
RF-DETR Small을 각 작업에 10 epochs 학습했습니다. 검증 mAP@50:95는 신발 종류 45.93%, 손상 부위 22.46%입니다. confidence 0.25에서 운동화 검출률 84.55%, 밑창 손상 33.33%, 안감 손상 77.42%입니다. 이전 손상 보고서의 9.5%/29.0%는 confidence 0.8 결과이며 모델이 달라진 것이 아닙니다.

검증 손상 박스 207개 중 148개가 사진 면적의 1% 미만입니다. 학습 박스는 안감 1,731개, 밑창 320개로 불균형합니다. 신발 종류도 운동화 6,492개에 비해 기타 89개, 슬리퍼 66개입니다. 슬리퍼와 not_sneakers는 검증 정답이 없어 성능을 판단할 수 없습니다.

## 추가 데이터 없이 가능한 대안

1. 작은 손상을 크게 보이게 학습합니다. 원본 사진 전체를 유지하면서 겹치는 타일을 추가하고, 타일 추론 결과를 원본 좌표로 합칩니다. 없는 디테일을 복원하는 것은 아닙니다.
2. 부족한 클래스의 학습 빈도를 높입니다. 이번에는 가장 취약한 밑창 손상이 포함된 학습 표본을 총 3회 등장시킵니다. 새로운 독립 표본이 늘어나는 것은 아니므로 과적합 위험을 함께 봅니다.
3. 학습 기간을 최대 30 epochs로 늘리고 조기 종료를 적용합니다. 처음에는 기존 학습률을 유지해 학습 기간 변화 효과를 분리합니다. 학습률 조정은 이 비교 이후 별도 실험으로 남깁니다.
4. 클래스별 임계값을 검증 데이터에서 분석합니다. 목표 검출률 미달 시 정밀도만 최대화하는 대신 F1 기준의 탐색용 값을 기록하고, 목표 미달 여부를 명시합니다.
5. 기존 라벨의 정의·누락·박스 일관성을 검토합니다. 이번 자동 실험에서는 정답 라벨을 임의로 수정하지 않습니다.
6. 실사용에서는 불확실한 결과를 정상으로 간주하지 않고 판정 보류로 보냅니다. 밑창은 사람의 검토를 돕는 보조 기능으로 시작하는 방안입니다. 이번 실행에서 운영 시스템을 변경하지 않습니다.

## 실행하는 실험

| 실행 이름 | 작업 | 데이터 변경 | 최대 epochs |
|---|---|---|---:|
| data1_long30 | 신발 종류 | 기존 학습 데이터 그대로 | 30 |
| data2_long30 | 손상 부위 | 기존 학습 데이터 그대로 | 30 |
| data2_tiles30 | 손상 부위 | 원본 + 사진당 4개 타일 | 30 |
| data2_tiles_balanced30 | 손상 부위 | 위 구성 + 밑창 포함 표본 총 3회 반복 | 30 |

모든 실험은 동일한 COCO 사전학습 모델에서 새로 시작합니다. 기존 10 epochs 결과를 이어 학습하는 방식이 아닙니다. 모델 RF-DETR Small, 입력 512, batch 2, 누적 8, seed 42, workers 0, EMA 비활성, 기존 학습률을 유지합니다. 검증 mAP 개선이 10 epochs 동안 없으면 조기 종료하며 best.pth 하나만 저장합니다. 실험마다 학습 표본 수가 달라 같은 epoch라도 계산량은 다르며, 순수한 동일 시간 예산 비교는 아닙니다.

타일의 가로·세로는 원본의 62.5%입니다. 512×512 사진에서는 320×320 크기의 네 모서리 타일이 되며 서로 겹칩니다. 박스는 잘린 면적이 원래 박스의 50% 이상이고 가로·세로가 2px 이상일 때 좌표를 변환해 유지합니다. 잘린 박스와 타일 경계의 영향은 결과 해석 시 고려합니다. 빈 타일도 포함하지만 이를 독립적으로 확인한 정상 신발 사진이라고 주장하지 않습니다. 1,222장의 손상 학습 원본에서 원본+타일 6,110개 입력이 만들어집니다.

원본 이미지·라벨 파일을 수정하지 않습니다. 반복 표본과 전체 프레임은 하드링크(불가하면 복사), 타일은 별도 파일로 저장합니다. 원본 분할을 먼저 유지한 뒤 train 안에서만 타일·반복 표본을 만듭니다. val은 원본 131장 그대로 유지합니다. test는 새 데이터셋에 만들거나 평가하지 않습니다.

## 공정한 평가와 산출물

- 학습 중 best 선택은 원본 전체 프레임 val mAP 기준입니다. 타일 추론 mAP가 최고인 epoch를 따로 고르는 방식은 아닙니다.
- 모든 모델을 같은 원본 val 사진·정답, confidence 0.25, 매칭 IoU 0.5, maxDets 300으로 비교합니다. AP 예측 하한은 0.001입니다.
- 타일 학습 모델은 전체 프레임 추론과 원본+타일 추론을 각각 평가합니다. 후자는 좌표 복원 후 클래스별 IoU 0.5 NMS로 중복을 합칩니다. 기존 10 epochs 손상 모델에도 동일 타일 추론을 적용해 추론 방식만 바꾼 효과를 따로 확인합니다.
- 타일 추론은 사진당 5회 추론하므로 속도 비용이 있습니다. 이 실험에서는 별도 지연시간 벤치마크를 하지 않습니다.
- 클래스별 AP·정밀도·검출률, 크기별 검출률, 원본 전체 프레임 오류 이미지, 학습 곡선, 클래스별 임계값 후보를 저장합니다. 임계값 후보는 각 클래스의 단독 통계이며 통합 배포 성능을 보장하지 않습니다.
- 같은 val로 반복 실험하므로 개선 수치는 탐색 결과입니다. 설정을 확정한 뒤 최종 test를 한 번 평가해야 합니다. 검증 표본이 없는 클래스의 개선은 입증할 수 없습니다.

## 실행 및 확인

실행 코드: `run_improvement_experiments.py`.

```powershell
.venv/Scripts/python.exe -u run_improvement_experiments.py `
  --baseline artifacts/local_gpu_20261015_213427 `
  --output artifacts/no_new_data_<실행시각> --epochs 30
```

실제 실행 경로와 PID는 `artifacts/active_improvement_run.json`에 기록합니다. 결과 폴더의 `status.json`은 실험별 진행 상태를, `results.md`와 `comparison.csv`는 완료한 평가 결과를 담습니다. 단계별 로그는 결과 폴더 바로 아래에 저장합니다. 특정 실험이 실패하면 오류를 status.json에 기록하고 다음 실험을 시도합니다. 마지막 상태가 completed_with_failures이면 실패 로그 확인이 필요합니다.

2026-10-16 시작한 실제 실행: `artifacts/no_new_data_20261016_014558`.
데이터 준비 결과는 타일 실험 train 6,110개, 밑창 균형 실험 train 7,928개이며 두 실험 모두 val 131장입니다. 좌표 변환·중복 예측 병합·train 전용 반복·원본 라벨 보존·임계값 저장을 포함한 전체 테스트 20개가 통과했습니다. 첫 초기 실행은 임계값 후보 저장 오류로 학습 전에 실패했으며, 해당 오류를 수정하고 위 경로에서 새로 시작했습니다.

여러 실험을 한 GPU에서 순차 실행하므로 완료까지 수 시간이 걸릴 수 있습니다. 큰 모델 교체, 새로운 라벨 생성, 기존 test 재분할은 이번 범위에 포함하지 않습니다. 결과를 확인한 뒤 학습률·밑창 반복 강도·크롭 비율의 다음 실험을 결정합니다.
