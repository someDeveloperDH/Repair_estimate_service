# 두 손상 동시 검사 및 교집합 기준 평가

요청 반영일: 2026-10-16. 이전 IoU≥0.5 운영 평가와 구분하는 새 평가 규칙입니다. 기존 결과 파일은 수정하지 않습니다.

## 손상 검출

RF-DETR는 밑창(outsole)과 안감(heel lining)의 후보 점수를 함께 출력합니다. 두 종류 중 한 개만 고르는 argmax 분류로 제한하지 않습니다. 한 이미지에 서로 다른 두 종류 또는 같은 종류의 여러 박스가 남을 수 있습니다.

추론·평가 결과의 `damage_presence`는 `both`, `outsole_only`, `heel_lining_only`, `no_damage_detected`를 기록하고 클래스별 검출 개수를 포함합니다. 미검출은 해당 임계값에서 두 손상 후보가 없다는 뜻이며 정상 보증이 아닙니다. not_sneakers는 손상 클래스가 아닙니다.

## 요청한 평가 규칙

- 예측 클래스와 정답 클래스가 같아야 합니다.
- 두 박스의 교집합 면적이 0보다 크면 정답 후보로 인정합니다. 가장자리의 선이나 한 점만 닿는 것은 제외합니다.
- 점수 내림차순으로 아직 매칭되지 않은 같은 클래스 정답 중 IoU가 가장 큰 정답에 일대일 매칭합니다.
- 같은 정답을 여러 번 검출하면 첫 매칭만 정탐입니다. 큰 예측 박스 하나로 여러 정답을 모두 맞힌 것으로 처리하지 않습니다.
- 매칭된 예측은 TP, 대응되지 않은 예측은 FP, 남은 정답은 FN입니다. 이를 정밀도·검출률·F1에 반영합니다.
- 별도의 `ap_any_overlap`는 이 매칭을 사용한 전체 예측 순위의 101점 보간 AP입니다. 표준 COCO AP50·mAP50:95는 그대로 다른 항목으로 기록합니다.

넓은 박스나 아주 작은 교집합도 정탐이 될 수 있습니다. 이 값은 위치가 정확하다는 의미의 기존 IoU 지표와 다릅니다. 모델을 다시 학습하거나 예측을 변경한 것은 아니므로 기준 변경으로 오른 점수를 모델 개선으로 해석하지 않습니다.

## 명령 및 호환성

`python -m pipeline.run`의 `--match-rule` 기본값은 `any_overlap`입니다. 이전 기준은 `--match-rule iou50`으로 실행합니다. RF-DETR 평가 결과는 선택한 기준의 운영 지표와 사용자 정의 AP, 비교용 IoU≥0.5 운영 지표와 표준 COCO AP를 함께 저장합니다.

임계값 파일에는 `matching_rule`을 함께 저장합니다. 예전 파일에 이 값이 없으면 iou50으로 간주합니다. 다른 기준에서 선택한 임계값을 조용히 재사용하지 않으며, 검증에서 새 임계값을 선택하거나 명시적 `--conf`로 탐색합니다. 기존 추론을 그대로 재현할 때에는 `--match-rule iou50`을 지정합니다.

`python -m pipeline.inference_trace`도 기본 `any_overlap`으로 정답 평가를 기록합니다. `--all-detections`는 사진의 모든 검출을 항목별 추적하며 두 클래스 검사를 기록합니다. 서비스와 자동 연동된 상태는 아닙니다.

저수준 `pipeline.metrics.match/evaluate`의 기본은 기존 호출 호환성을 위해 iou50을 유지합니다. 새 기준을 사용하는 코드는 `rule='any_overlap'`을 명시합니다. 따라서 과거 분석 스크립트를 재실행해도 암묵적으로 과거 해석이 바뀌지 않습니다.
