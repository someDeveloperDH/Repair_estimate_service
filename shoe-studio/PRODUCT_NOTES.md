# SOLE 신발 수선 UI 시안

React 기반의 반응형 웹 프로토타입입니다. 학습 프로세스와 별도 폴더에서 실행합니다.

## 사용 흐름

1. 같은 상품 사진을 최대 12장 등록합니다. JPG/PNG/WEBP, 장당 15MB 이하를 지원합니다.
2. 목록의 `1st`로 대표 사진을 정합니다. 대표 사진에서 신발 여부·종류를 먼저 판정하는 흐름입니다.
3. 등록 완료 후 사진을 순차 확인하는 데모가 진행됩니다.
4. 왼발/오른발, 측면/윗면/밑창의 2D 모형에서 손상 기록을 선택합니다.
5. 같은 발·부위·손상 종류는 기록을 합치고 근거 사진만 추가합니다. 수동 입력 시 같은 부위의 별도 손상으로 기록할 수도 있습니다.
6. 항목별 가격과 합계를 표시합니다. 현재 모든 가격은 0원이며 `단가 미설정`을 명시합니다.
7. 견적 기록을 JSON으로 내려받을 수 있습니다.

## 실제 동작과 데모 경계

실제 동작: 파일 추가·삭제, 대표 사진 변경, 사진 미리보기, 보기 전환, 기록 병합, 직접 추가·삭제, 근거 사진 이동, 합계 계산, 견적 JSON 내보내기.

데모: 신발 여부·종류 판정, 손상 검출과 위치 대응. 판정 시나리오를 선택할 수 있고 사진 내용과 무관한 고정 예시 손상을 표시합니다. 원격 AI 호출이나 모델 로딩은 하지 않습니다. 종류별 전용 모형이 아닌 공통 신발 도식을 사용합니다. 샘플 사진도 SVG 예시입니다.

사진 파일과 결과는 브라우저 메모리에만 존재합니다. 서버 업로드, 계정별 저장, 새로고침 후 복원은 구현하지 않았습니다. Google Fonts에서 웹폰트를 불러옵니다.

## 모델 연결 시 필요한 설계

- 첫 사진의 결과가 `신발 아님` 또는 `판정 보류`이면 사용자에게 대표 사진 변경을 요청합니다. 현재 7종 모델만으로 비신발 거절을 보장할 수 없으므로 별도 검증이 필요합니다.
- 관찰 결과는 `상품 ID / 사진 ID / 발 방향 / 해부학적 부위 / 손상 종류 / 박스 / confidence`로 저장합니다.
- 손상 기록은 독립 ID를 가지고 여러 사진 관찰을 참조합니다. 동일 부위·종류라는 이유만으로 무조건 병합하지 않고 별도 손상일 가능성을 남겨둡니다.
- 사진의 2D 박스를 공통 모형의 부위로 옮기려면 촬영 방향·신발 방향·부위 판별이 추가로 필요합니다. 현재 검출 모델만으로 자동 해결되지 않습니다.
- 초기에는 사용자가 왼발/오른발·부위를 확인하는 방식이 현실적입니다. 병합 후보를 제안하고 수동 분리·합치기를 지원하는 것이 다음 단계입니다.
- AI confidence와 수선 가능 여부·비용은 별개입니다. 금액표와 수선 항목 대응 규칙을 별도로 관리합니다.

## 실행

```powershell
node scripts/run-framework.mjs dev
```

기본 로컬 URL은 http://127.0.0.1:5173 입니다. TypeScript 검사는 `node node_modules/typescript/bin/tsc --noEmit`, 빌드는 `node scripts/run-framework.mjs build`입니다. Windows 환경의 npm shim 문제를 피하려면 npm CLI를 절대 경로로 호출할 수 있습니다.
